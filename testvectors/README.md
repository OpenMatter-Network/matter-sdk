# Cross-language conformance vectors

Fixtures generated by the Rust core and replayed by every binding, which must reproduce
them byte-for-byte.

| File | What every binding must reproduce |
|---|---|
| `signing_payload.json` | the exact bytes a requester signs for `/partial-decrypt`, including the per-node `recipient_index` bound into the payload |
| `lagrange.json` | the bincode Lagrange coefficient for a node over a subset |
| `open_secret.json` | a sealed secret + a real committee quorum, each partial labelled with its node's `point`; `openSecret` must recover `expected_plaintext_hex` (the core derives each Lagrange coefficient from the points) |
| `seed_formats.json` | one sr25519 secret in both encodings (`0x`-hex mini-secret and BIP39 mnemonic) must derive `account_id_hex`; also replayed by the dashboard that mints API keys |
| `api_keys.json` | the full API-key ingestion contract: `valid` keys must parse to `account_id_hex`, `invalid` keys must be rejected with the named error kind |
| `facade_calls.json` | the curated façade surface: which `(façade, method)` pairs exist and which `(pallet, call)` or runtime API each maps to |
| `scope_bits.json` | the `ScopeSet` wire contract: bit = `scope * 2 + access`, encoded as a bare `u32`, plus an `is_superset` truth table where Read and Write are independent |
| `networks.json` | the default RPC endpoint per network name (`null` = no default). **Hand-maintained**, not emitted; must point at a host serving public RPC. Replayed by each binding's default-endpoint test |
| `required_scopes.json` | what every call of the ten scoped pallets requires of a delegated key; `required: null` for calls no key may ever make |

`api_keys.json` is kept separate from `seed_formats.json` because the latter is a
positive-only vector shared with the dashboard. Two `api_keys.json` cases matter most:

- **Junctions must be applied.** `0x…//hard` derives a *different* account than `0x…`;
  routing hex SURIs to a raw-seed constructor silently derives the root account.
- **A phraseless SURI must be rejected.** Most SURI parsers resolve `//Alice` against the
  public development phrase, turning an unset environment variable into a
  globally-controlled signer.

Encoding: binary fields are bare lowercase hex (no `0x`), except the `key` field of
`api_keys.json`, which is the literal pasted string (keeps its `0x` prefix and
whitespace). `secret_id` is a decimal string (`u128`).

## Regenerate

After any change to the cryptographic core, regenerate and re-run every binding's
conformance suite:

```bash
cargo test -p matter-sdk-core --test roundtrip -- --ignored
cargo test -p matter-sdk --test seed_formats -- --ignored
cargo test -p matter-sdk-key --test parse -- --ignored
cargo test -p matter-sdk --features chain --test facade_calls -- --ignored
cargo test -p matter-sdk --features chain --test scope_vectors -- --ignored
```

Replay sites:

- `api_keys.json`: `crates/matter-sdk-key/tests/parse.rs`,
  `packages/typescript-core/test/api-key.test.ts`, `bindings/python/tests/test_api_key.py`,
  `packages/go/mattersdk/apikey_test.go`.
- `facade_calls.json`: `packages/typescript/test/facade.test.ts`,
  `bindings/python/tests/test_facade.py`, `packages/go/mattersdk/facade_test.go`. Each
  checks **both ways**: a fixture row without a method fails, and a method without a row
  fails. Rust has no reflection, so its emitter test pins the list, and
  `fixture_args_match_the_runtime_fields` checks every row's argument names and arity
  against the metadata.
- `required_scopes.json`: replayed **one way** only (each binding classifies every row;
  a call missing from the fixture fails nothing). Completeness comes from generation: CI
  re-runs the emitter and fails on any diff, and the nightly `runtime-drift` workflow
  checks the live chains. The two `arg_sensitive` rows pin only their name-derived half;
  each binding tests the argument-dependent part itself.

`required_scopes.json` is generated from `spec330_metadata.scale`; when the runtime adds
a call, regenerate that blob first (recipe in `crates/matter-sdk/src/chain/scopes_table.rs`).

Two metadata blobs of the same runtime:

- `spec330_metadata.scale`: **V15**, what subxt and @polkadot load; the only version with
  runtime-API declarations (Rust resolves `BudgetsApi_agent_key` from it).
- `spec330_metadata_v14.scale`: what `state_getMetadata` returns and all GSRPC and
  substrate-interface can decode; Go pins its argument-sensitive scope rows against it.

`open_secret.json` is ~4 MB because RLWE capsules and ZK proofs are; that is the real
wire size.
